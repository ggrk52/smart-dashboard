# 🗺️ Magic Mirror LAN — Roadmap & Status

> Актуальный статус функционала и список идей/улучшений для локальной версии.

## ✅ Ужe реализовано (Current Features)

- [x] **🎨 Погода (Open-Meteo):** Прямая интеграция с Open-Meteo (прогноз, WMO-коды, гибкая настройка города/координат через `/api/mirror/weather/config`).
- [x] **🗓️ Календарь (iCal / Google / Яндекс):** Загрузка и парсинг `.ics` календарей по URL, парсинг событий и вывод ближайших запланированных встреч через `/api/calendar/events`.
- [x] **🖼️ Управление галереей:** Загрузка, удаление и просмотр кастомных фотографий/картин (`GET/POST/DELETE /api/gallery`).
- [x] **📊 Курсы валют и криптовалют:** Динамическое получение данных CBR (рубль, евро, доллар) и CoinGecko (BTC, ETH), включая историю изменений (`/api/markets/history`).
- [x] **📰 Новости:** Автоматический парсинг RSS-ленты ТАСС в реальном времени.
- [x] **🔔 Toast-уведомления и нотификации:** Вывод временных системных всплывающих уведомлений на экран зеркала (Toast).
- [x] **🎭 AR / HUD режим:** Сканирование лица и визуализация пульса с помощью BlazeFace / TensorFlow.js.
- [x] **🎨 Кастомизация акцентных цветов:** Настройка акцентного цвета UI из Android-приложения (`POST /api/mirror/accent`).
- [x] **🍊 Поддержка железа:** Полная поддержка управления экраном и GPIO на Orange Pi / Linux, systemd-сервис и авто-скрипт установки.

- [x] **🌡️ Температура CPU в `/api/diagnostics`:** `HardwareManager.getTemperature()` интегрирован в `/api/diagnostics` сервера и отображается бейджем в Android StatusCard.
- [x] **📸 Прогресс-бар загрузки фото в Android:** Отображение реального прогресса загрузки файлов через `uploadProgress` и `LinearProgressIndicator`.
- [x] **🛡️ Безопасность и Telemetry:** Удален жестко закодированный API ключ телеметрии, добавлен in-memory rate limiting для эндпоинтов загрузки.

## 🔴 High Priority — Reliability & UX

### 🔁 WebSocket auto-reconnect на уровне сервера
**Проблема:** Если клиент (браузер) потерял соединение и переподключился — он получает текущее состояние только при новом handshake.  
**Идея:** Хранить последние N событий в кольцевом буфере и отправлять их при переподключении (`since` timestamp в query параметре).

## 🟡 Medium Priority — Features

### ⏰ Расписание включения/выключения экрана
**Идея:** Добавить cron-расписание для автоматического вкл/выкл экрана по времени.  
```json
{ "schedule": [{ "on": "07:00", "off": "23:00", "days": [1,2,3,4,5] }] }
```
Хранить в `server/data/schedule.json`, выполнять через `setInterval` или `node-cron`.

---

### 🔊 Управление громкостью через GPIO / ALSA
**Идея:** `HardwareManager` имеет доступ к командам. Можно добавить управление аудиовыходом через `amixer` (ALSA) на Orange Pi и эндпоинт `POST /api/audio/volume`.

---

### 🌐 Мультиязычность браузерного UI
**Текущее состояние:** UI полностью на русском языке.  
**Идея:** Вынести все строки в `server/public/js/i18n/ru.js` и `en.js`, переключение через `?lang=en` или `localStorage`.

## 🟢 Low Priority — Nice to Have

### 📱 Виджет «Кто дома» (presence detection)
**Идея:** Пинговать MAC-адреса устройств в LAN через ARP, определять присутствие членов семьи дома. Показывать на зеркале. Использует `arping` или `/proc/net/arp`.

---

### 🔐 HTTPS / mTLS
**Текущее состояние:** Сервер работает по HTTP (задуман для LAN).  
**Идея:** Опциональный режим с самоподписанным TLS-сертификатом (через `node:tls`).

---

### 🎙️ Голосовое управление (локальное)
**Идея:** Интеграция с [Vosk](https://alphacephei.com/vosk/) для оффлайн распознавания речи прямо на Orange Pi. Команды типа «зеркало, выключись», «покажи картину» через существующий REST API.

---

### 🌙 Адаптивная яркость по времени суток
**Идея:** `HardwareManager` управляет backlight. Добавить плавное снижение яркости в ночное время через `setInterval` + таблицу `яркость = f(час)`.

---

### 📦 Docker-образ для сервера
**Идея:** `Dockerfile` + `docker-compose.yml` для запуска сервера в контейнере. Удобно для тестирования без Orange Pi и для CI.
